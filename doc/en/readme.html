Add-on Developer Updater

This add-on checks official NVDA releases and safely monitors approved NVDA add-on development projects in configured folders and locally synchronized cloud storage.

Commands

Press NVDA+Alt+Shift+U to start a manual check. The command can be changed or removed under Add-on Developer Updater in NVDA's Input Gestures dialog. An unassigned cancel command is also available there.

Safety

Automatic changes are disabled by default. A manual scan approves the projects it finds; projects first found by background discovery wait for manual approval. Only projects containing Git metadata or recognized NVDA build files are eligible. Installed add-ons, packages, output folders, system folders, caches, translations, runtime tests, and cloud-only placeholders are ignored. Required metadata and Python syntax are validated first. Every changed manifest receives a project-specific backup in the active NVDA configuration folder.

Settings

Use NVDA Settings, Add-on Developer Updater to control automatic checks, prereleases, opt-in automatic changes, additional approved roots, full-drive manual discovery, release intervals, and periodic rescanning.

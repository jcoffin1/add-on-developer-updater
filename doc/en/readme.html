Add-on Developer Updater

This add-on checks official NVDA releases and finds NVDA add-on development projects on accessible drives and in locally synchronized cloud folders.

Commands

Press NVDA+Alt+Shift+U to start a manual check. The command can be changed or removed under Add-on Developer Updater in NVDA's Input Gestures dialog. An unassigned cancel command is also available there.

Safety

Only projects containing Git metadata or recognized NVDA build files are changed. Installed add-ons, packages, output folders, system folders, caches, translations, and cloud-only placeholders are ignored. Required metadata and Python syntax are validated first, and every changed manifest is backed up in the active NVDA configuration folder.

Settings

Use NVDA Settings, Add-on Developer Updater to control automatic checks, prereleases, automatic changes, drive scanning, and the check interval.
